## Version 1.11.0 - The Water World Update
 - Expanded the world map to about 150% scale, to make room for four new archipelago nations to the east and south of the continent, Kulcin, Uxbrid, Gacte, and Ishkari.
 - Rotated the world map by 6 degrees clockwise. 
 - New Map file necessitated tweaks to biomes and cultures. 
 - Added the Lewen archipelago 
 - Added about 140 islands to the Shattered Sea
 - Expanded Eplem's and Arutu's shorelines, and a bit of Halderok's
 - Added Portshil in Eplem
 - Adjusted all State Labels
 - Route rework and addition of sea routes
 - Added Wind Rose to indicate wind direction
 - Learned why rivers weren't working and that basically nothing can be done :/
 - Several towns adjusted to have ports for sea route functionality 

## Version 1.10.1 - The Style Upgrade
 - Adjusted styles for burgs (Cities, Towns, Villages, and Abandoned styles)
 - Added Foyya to Fratera
 - Undid river overhaul following issues with implementation
 - Converted The Drifting Mist Temple, Atlantis Graveyard, and Michael's Cabin into burgs with the abandoned style for better visibility

## Version 1.10.0 - World of Life Update
 - Added Physical (Geographic) Map view
 - Complete overhaul of biomes and climates
 - River overhaul
